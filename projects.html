Vision-based tracking robot

Summer 2026 · C · Python · STM32 · Raspberry Pi 5 · UART · I²C · PID · code

A pan/tilt robot that follows your hand. A Raspberry Pi 5 runs YOLO hand detection on the Pi Camera feed and sends target angles over UART to an STM32 Nucleo-F446RE, which runs a 160 Hz PID loop on two DC gearmotors with absolute encoders read over I²C. All the firmware is bare-metal C.

The main problem was that the turret kept hunting back and forth around the target. It turned out the camera frame and the encoder reading were from slightly different moments, so I estimated where the camera actually was when each frame was captured. That fixed the hunting without adding delay. Adding measured friction feedforward cut steady-state error from 4° to 1°, and gating the deadband on target velocity raised motor engagement during tracking from 38% to 98%.

"The Lick" melody generator

Fall 2025 · Verilog · Basys2 FPGA · code

A finite-state machine in Verilog that plays the ifamous jazz lick on a piezo buzzer. I built clock dividers and counters off the 50 MHz system clock to generate each note's square wave and time the notes in 0.2 s steps.
